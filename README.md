# 手机银行系统

​		一个基于 Python 开发的命令行手机银行系统，支持用户注册、登录、存取款、转账、查询等核心 banking 功能。采用多层安全机制保障用户资金安全。

## ✨功能特性

| 功能模块 |                 描述                 |
| :------: | :----------------------------------: |
| 用户认证 |    注册、登录、退出登录、注销账户    |
| 资金管理 |      存款、取款、转账、余额查询      |
| 交易记录 |           查看账户明细流水           |
| 安全设置 | 修改密码、密码错误锁定、密码加密存储 |

## 🛠️系统要求

- **Python**：python 3.6+
- **依赖**：无需第三方库（仅使用 Python 标准库）
- **操作系统**：Windows

## 📖功能说明

### 用户注册

- 输入手机号（自动格式校验）

- 输入用户名、密码、确认密码

- 检测手机号是否已注册

- **安全机制**：密码加密存储

- 新用户数据保存至 `user_data/` 目录，以手机号命名

### 用户登录

- 输入手机号和密码进行验证
- **安全机制**：密码连续输错 3 次自动退出系统
- 未注册用户自动引导至注册流程

### 存款

- 输入存款金额（自动校验金额合法性）
- 实时更新余额并记录交易流水

### 取款

- 输入取款金额
- 校验余额是否充足
- 更新余额并记录流水

### 转账

- 输入收款人手机号和用户名验证
- 输入转账金额和密码
- **安全机制**：密码连续输错 3 次返回主页
- 实时扣款并记录双方流水

### 查询功能

- 查看余额：显示当前账户余额
- 查看明细：展示完整交易流水记录

### 账户管理

- 修改密码：需验证原密码，新密码不可与原密码相同
- 退出登录：清除登录状态，返回主菜单
- 注销用户：永久删除账户数据文件

## 🛡️安全特性

### 认证安全

| 安全措施       | 说明                             |
| -------------- | -------------------------------- |
| 手机号格式校验 | 正则表达式验证 11 位手机号合法性 |
| 密码强度校验   | 基础长度和复杂度检查             |
| 密码加密存储   | 采用哈希算法，非明文保存         |
| 错误尝试锁定   | 连续 3 次密码错误自动退出系统    |

### 交易安全

| 安全措施     | 说明                          |
| ------------ | ----------------------------- |
| 交易密码确认 | 转账等敏感操作需二次密码验证  |
| 转账双重验证 | 验证收款人手机号 + 用户名匹配 |
| 余额充足校验 | 取款/转账前强制检查余额       |
| 事务一致性   | 转账操作双方账户同步更新      |

### 数据安全

| 安全措施     | 说明                       |
| ------------ | -------------------------- |
| 文件隔离存储 | 每个用户独立 JSON 文件     |
| 敏感信息加密 | 密码字段加密存储           |
| 原子性操作   | 关键操作异常时数据回滚保护 |
